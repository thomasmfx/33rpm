# Frontend do 33rpm

Aplicação React + TypeScript + Vite, com a suíte Cypress em `cypress/`.

Instalação, execução, variáveis de ambiente e testes estão documentados no
[README da raiz do repositório](../README.md).

Atalhos, a partir desta pasta:

```bash
npm install
npm run dev        # loja em http://localhost:3300
npm run e2e        # testes de interface, com banco e API no ar
npm run lint
npm run build
```
