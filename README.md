## Tema

**33rpm:** E-commerce de discos de vinil com uma experiência de descoberta baseada em sonoridades, "moods" (climas), estéticas e subgêneros detalhados (ex: "rap psicodélico" ou "jazz para dias de chuva"), indo além da busca tradicional por artista/título.

## Stack Tecnológica

- **Frontend:** React.js + TypeScript
- **Backend:** Java + Spring Boot
- **Banco de Dados:** PostgreSQL
- **Testes:** Cypress

## Inteligência Artificial

- **IA integrada/chatbot:** Dify.ai + Google AI Studio API
- **IA de desenvolvimento:** Claude e Gemini
